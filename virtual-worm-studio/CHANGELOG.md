# Changelog

## 1.5.0 — 2026-11-19

- Portable source launchers for macOS, Windows, and Linux, using Python's standard library.
- Included prepared anatomy and local rendering libraries; optional original .blend download.
- Browser setup controls for an external Blender executable and local original model path.
- GitHub-friendly compressed anatomy parts with checked cache extraction.
- Cross-platform export filenames; settings changes preserve model/Blender configuration.
- README, attribution, maintainer/release instructions, tests, and three-OS build workflow.
- Retains 1.4.2 nested tissue boundaries and per-object Filled/Outline controls.

## 1.4.2 — Local macOS app

- Retain individual silhouettes for anatomy enclosed by an outlined cuticle.
- Add Filled/Outline controls alongside each cell's color.
- Preserve selected organs/styles when clicking the cuticle.
