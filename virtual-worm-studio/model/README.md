# Save the original Virtual Worm file here

Visit the [Virtual Worm website](https://caltech.wormbase.org/virtualworm/)
and follow **Download Virtual Worm .blend File**. Choose
`Virtual_Worm_February_2012.blend` and save the actual Blender file in this folder.
The [instructional videos](https://caltech.wormbase.org/virtualworm/Instructional_Videos.html)
explain the original model.

The original website's linked [download directory](http://canopus.caltech.edu/virtualworm/Virtual%20Worm%20Blend%20File/)
may also be useful. This is a legacy site; if a link is unavailable, return to
the project homepage for its current download link. An HTML page renamed to
`.blend` is not the model. Do not use the January/June/March versions with
this prepared February 2012 catalog.

Restart the app after saving the file here, or enter the full path in
**Model & Blender setup**. The viewer, PNG, GLB, and CSV already work using
the included prepared anatomy. Only editable `.blend` extraction requires
the original file and an independently installed compatible Blender.
