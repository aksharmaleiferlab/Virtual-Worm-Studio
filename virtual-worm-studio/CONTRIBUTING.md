# Contributing

Read [README.md](README.md) and [docs/MAINTAINERS.md](docs/MAINTAINERS.md).
Run the Python and optional Node tests before proposing a change. For rendering
changes, test a cuticle outline with filled and outlined internal organs and
include a screenshot. Record the actual OS/browser/GPU used for visual tests.

Preserve original spatial coordinates, optional `.blend` setup, offline operation,
source-model attribution, and portable export behavior. Do not commit user settings,
logs, figures, cache, Blender binaries, or a downloaded original `.blend`.
Describe expected versus observed behavior and reproduction steps in issues.
